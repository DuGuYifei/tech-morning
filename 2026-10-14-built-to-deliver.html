01 / GEMINI 4 ARGON扩大可用

Argon开放了，
长任务预算怎么设？

百万级窗口，是输入、思考和输出的共同预算。

Google 10月13日扩大 Gemini 4 Argon 的公开可用范围，开发者可在 Gemini API 付费层接入。它并非当日首次亮相：9月30日首发阶段主要面向受信任的网络防御伙伴。本期聚焦 API，不把不同消费产品的订阅权限混为一谈。

官方文档规定，输入、思考与输出共享1,048,576 token窗口。若要生成超过64K的长响应，需要设置更高的 max_output_tokens 并使用后台执行或分段续接；只打开后台执行、没有提高输出上限，仍会停在64K。完成后还要拼接各段 model_output。

迁移另有两个易漏点：显式上下文缓存暂不支持，temperature、top_p、top_k会被忽略。Google将其定位于复杂编码和多步骤Agent；这是厂商能力描述，本刊没有独立性能实测。

编辑判断 / 先算完整任务

先用已有回归任务测质量、总token、超时和完整结果拼接，再逐步增加流量。更长输出不是可靠性的保证，思考也会占用输出预算，不能只按最终可见文字估算开销。

02 / TANSTACK START全栈框架

Start 1.0稳定了，
边界仍要自己画

类型可以约束接口，却不会替你判断产品是否做对。

Tanner Linsley 10月13日宣布 TanStack Start 1.0 稳定版，结束RC阶段。框架提供服务端渲染、客户端渲染、类型化 server functions，以及贯穿客户端和服务端的中间件。

Netlify同日宣布部署支持，SSR、server routes、server functions和middleware由Netlify Functions承载。新建Agent Runners项目默认使用Start 1.0，除非另行指定框架；这不代表现有项目会自动迁移。

维护者认为，显式API和类型约束有助于Agent发现改动后的不一致；也提醒类型无法判断产品意图。1.0稳定承诺不等于所有旧应用都能无成本迁移。

编辑判断 / 先做一个纵向切片

挑一个同时需要交互和服务端数据的页面，验证类型检查、鉴权、数据运行位置与部署适配。把浏览器与服务端的信任边界写清楚，再谈扩大迁移；不要把类型安全当成运行时安全审计。

LOCAL AGENTS
arXiv:2610.11482 · v1
2026.10.08

让Agent修复，
还要独立验收

近期论文选读：给本地模型一个可检查、可修复的工作区，会发生什么？

研究在单张RTX 4090上，以15项交通数据工程任务测试10种本地Qwen配置。一次生成与工具闭环两种模式各重复5次，共1,500次。闭环允许读写文件、执行命令、检查并修复产物；提交后才由隐藏的确定性检查器评分。

作者实验 / 产物通过率

Qwen 3.5 9B Q4从一次生成的17.3%升至闭环的69.3%，增加52个百分点；Qwen 3.6 27B Q4在闭环中达到85.3%。这是特定任务集上的作者实验，不是通用Agent成功率，本刊未下载复现包或复跑。

局限与适用场景

固定离线数据、单一模型家族限制了外推；工具、反馈和多轮上下文共同变化，不能把增益归因于某个组件。编辑判断：适合借鉴到可自动验收的数据清洗与转换，先定义字段、数值和文件约束，再允许修复，并保留提交后的独立检查。

04 / MICHELANGELUS字体设计

一个小写g，
打磨了一周

把米开朗基罗的视觉语言带进文档，靠的不是把手迹直接扫描成字体。

微软10月8日介绍新字体Michelangelus。Studiogusto从手稿、签名和石刻中提炼字形，再为现代阅读重新设计；设计师为一个小写g花了一周。四种样式合计超过2,000个字形，也补上历史材料里没有的现代字符。

字体现可下载，微软计划年底分发到Word、PowerPoint和Excel，不能写成现在已全面内置。它是现代字体设计，不是完整手迹复刻，也不是中文字体；使用和再分发仍需查看对应许可。

编辑观察 / 把灵感变成系统

一个字符好看还不够，还要能和其他字符、数字与标点一起工作。字体设计的有趣之处，恰在于把历史中的个性转成可重复使用的规则。本期未复制官方字形或宣传图片。

BEFORE YOU GO / 收刊

把完成，
写成可检查的条件。

今天可以为一个常用Agent任务补一条验收规则：结果必须包含哪些字段、满足什么约束、由哪一步独立检查。先让“完成”有定义，再让系统跑得更远。
